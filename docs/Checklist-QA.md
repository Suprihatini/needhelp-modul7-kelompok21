# Checklist QA

## Starter

Catatan hasil aktual akan ditulis di Hasil-Verifikasi.md. Jangan menganggap seluruh checklist aplikasi final sudah lulus.

## Aplikasi final — wajib dikerjakan Felix Nicholas Juan Lee

- [ ] Clone repository publik ke folder baru, npm ci dan npm run build berhasil.
- [ ] Login kosong, format salah, password salah, dan kredensial demo benar berfungsi.
- [ ] Logout dan kebijakan penyimpanan sesi sesuai PRD.
- [ ] Beranda dan katalog sesuai Figma pada desktop/tablet/mobile.
- [ ] Filter benar-benar mengubah hasil dan menangani hasil kosong.
- [ ] Drawer mobile dapat dibuka, ditutup, dan dipakai navigasi.
- [ ] Klik kartu membuka detail postingan yang benar.
- [ ] Form salah menampilkan error; form valid menghasilkan sukses.
- [ ] Hasil submit tampak pada aktivitas sesuai cakupan data demo.
- [ ] Chat/notifikasi sesuai cakupan final.
- [ ] Tidak ada tombol penting yang tanpa respons; fitur simulasi dijelaskan.
- [ ] Aset asli lokal tersedia; tidak ada gambar rusak/URL Figma sementara.
- [ ] Tidak ada overflow horizontal pada 360, 390, 768, 1440 piksel.
- [ ] Navigasi keyboard, label input, pesan error, fokus modal diperiksa.
- [ ] Tidak ada crash/runtime error pada alur utama.
- [ ] Minimal 5 commit nyata dan deskriptif; repo dapat dibuka publik.
- [ ] README/PRD PDF memuat link, cara lokal, kontribusi, prompt/perbaikan.

Format bug: ID | layar | langkah reproduksi | diharapkan | aktual | ukuran layar | penanggung jawab | status.
